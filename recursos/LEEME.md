# Recursos para generar flashcards

Crea una carpeta por asignatura con el mismo nombre que en la app, por ejemplo `Física II`, y sube ahí los apuntes (PDF, imágenes, .md, .txt, .docx).

Cada mañana, Claude genera las flashcards de los archivos nuevos o modificados y aparecen en la app.

Ojo: este repositorio es público. No subas nada que no quieras que se pueda ver.
